# 🚀 Termux-DLX Pro
**The Ultimate High-Quality Media Downloader for Termux.**

## ✨ Features
- 📺 **High Quality:** Supports up to 4K resolution (using FFmpeg).
- 📱 **Multi-Platform:** Download from YT, Insta, FB, and more.
- 🎨 **Pro UI:** Beautiful ASCII banners and colorful menus.
- 📂 **Auto-Scan:** Automatically refreshes Android Gallery.

## 📥 Installation & Setup
Termux kholo aur ye commands ek-ek karke chalao:

```
git clone https://github.com/raghavansh50-cell/Termux-DLX-Pro
cd Termux-DLX-Pro
bash setup.sh
python downloader.py
```
